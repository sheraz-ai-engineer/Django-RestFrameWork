Now your question is:

> If Django Models are database models, then what do we use for input validation?

Excellent question.

The answer depends on whether we're using **plain Django** or **Django REST Framework (DRF)**.

---

# FastAPI

For input validation:

```python
from pydantic import BaseModel

class UserCreate(BaseModel):
    name: str
    age: int
```

Used here:

```python
@app.post("/users")
def create_user(user: UserCreate):
    ...
```

Pydantic validates the request.

---

# Django REST Framework

We use:

```python
Serializer
```

or

```python
ModelSerializer
```

Example:

```python
from rest_framework import serializers

class UserSerializer(serializers.Serializer):
    name = serializers.CharField(max_length=100)
    age = serializers.IntegerField()
```

Think:

```text
Pydantic Model
=
DRF Serializer
```

---

# Example Validation

FastAPI:

```python
class UserCreate(BaseModel):
    name: str
    age: int
```

Request:

```json
{
  "name": "Ali",
  "age": "hello"
}
```

FastAPI:

```json
{
  "error": "age must be integer"
}
```

---

DRF:

```python
class UserSerializer(serializers.Serializer):
    name = serializers.CharField()
    age = serializers.IntegerField()
```

Request:

```json
{
  "name": "Ali",
  "age": "hello"
}
```

DRF:

```json
{
  "age": [
    "A valid integer is required."
  ]
}
```

Same idea.

# Then What Is ModelSerializer?

Suppose you already have:

```python
class User(models.Model):
    name = models.CharField(max_length=100)
    age = models.IntegerField()
```

Instead of rewriting fields:

```python
class UserSerializer(serializers.Serializer):
    name = serializers.CharField()
    age = serializers.IntegerField()
```

DRF can automatically generate them:

```python
class UserSerializer(serializers.ModelSerializer):

    class Meta:
        model = User
        fields = "__all__"
```

This does:

1. Input validation ✅
2. Output serialization ✅
3. Connects to database model ✅

# FastAPI Translation

Think:

| FastAPI           | DRF             |
| ----------------- | --------------- |
| SQLAlchemy Model  | Django Model    |
| Pydantic Model    | Serializer      |
| Pydantic from ORM | ModelSerializer |
