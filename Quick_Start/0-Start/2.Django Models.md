# Topic 2: What is a Model?

This is the MOST important Django concept.

Honestly, if you understand Models, about 40% of Django becomes easier.

---

## First: FastAPI

Let's say you have a user.

You may create a Pydantic model:

```python
class User(BaseModel):
    name: str
    email: str
```

Question:

Does this create a database table?

❌ No

It only validates data.

---

To create a database table in FastAPI, you'd usually use SQLAlchemy:

```python
class User(Base):
    __tablename__ = "users"

    id = Column(Integer, primary_key=True)
    name = Column(String)
    email = Column(String)
```

Now a database table can be created.

---

# Django Model

In Django:

```python
from django.db import models

class User(models.Model):
    name = models.CharField(max_length=100)
    email = models.EmailField()
```

This is a **Model**.

A Model describes:

```text
What data should be stored in the database?
```

---

# Real Example

Suppose we are building a Todo App.

In Django:

```python
class Todo(models.Model):
    title = models.CharField(max_length=200)
    completed = models.BooleanField(default=False)
```

This means:

Database table:

| id | title        | completed |
| -- | ------------ | --------- |
| 1  | Learn Django | False     |
| 2  | Learn DRF    | True      |

# Easy Memory Trick

When you see:

```python
class Something(models.Model):
```

your brain should immediately think:

> "Ah, this is a database table."

Not:

> "This is an API schema."
