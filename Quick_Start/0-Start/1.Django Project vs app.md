# Topic 1: Django Project vs Django App

This is the thing that confuses almost every beginner.

---

## First, think about a FastAPI project

Imagine you're building an e-commerce API.

In FastAPI you might organize it like:

```text
ecommerce/
│
├── main.py
├── routers/
│   ├── users.py
│   ├── products.py
│   └── orders.py
│
├── models/
├── schemas/
└── database.py
```

You have:

* users routes
* products routes
* orders routes

All inside one project.

---

## Django thinks differently

Django says:

> Every major feature should be its own "app".

Example:

```text
ecommerce_project/
│
├── users_app/
├── products_app/
├── orders_app/
│
└── manage.py
```

Notice something?

What you might make as:

```text
users.py router
```

in FastAPI

often becomes:

```text
users app
```

in Django.

---

# What is a Project?

A **Project** is the entire website/API.

Example:

```text
Amazon
```

could be one Django Project.

Inside Amazon you have:

```text
Users
Products
Orders
Payments
Reviews
```

Each can be a separate Django App.

---

# What is an App?

An App is one feature/module.

Example:

### Users App

Responsible for:

```text
register user
login user
profile
```

### Products App

Responsible for:

```text
create product
list products
delete product
```

### Orders App

Responsible for:

```text
place order
cancel order
history
```

---

# FastAPI Translation

Think:

```text
Django Project
=
Entire FastAPI Project
```

and

```text
Django App
≈
Large FastAPI Router/Module
```

Not exactly the same, but close enough for now.

---

# Creating Them

Create project:

```bash
django-admin startproject mysite
```

Creates:

```text
mysite/
│
├── manage.py
└── mysite/
    ├── settings.py
    ├── urls.py
```

---

Create app:

```bash
python manage.py startapp users
```

Creates:

```text
users/
│
├── models.py
├── views.py
├── admin.py
├── apps.py
└── tests.py
```

This app now handles user-related functionality.

---

# Real Example

Suppose you're building a blog.

FastAPI brain:

```text
blog/
├── posts_router.py
├── comments_router.py
```

Django brain:

```text
blog_project/
│
├── posts_app/
├── comments_app/
```

Same idea, different organization.

---

# Super Important Rule

A Django Project can contain many Apps.

Example:

```text
Netflix Project
│
├── users app
├── movies app
├── subscriptions app
├── payments app
```

One project.

Many apps.
