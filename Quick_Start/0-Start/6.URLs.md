# Topic: URLs / Routing in Django REST Framework

In simple words:

> **URL routing means connecting a URL path to a View.**

You already know **Views**:

```python
class TodoView(APIView):
    def get(self, request):
        return Response({"message": "Todos list"})
```

But Django needs to know:

```text
Which URL should call this view?
```

That job is done by `urls.py`.

---

# 1. FastAPI way

In FastAPI, URL and function are together:

```python
@app.get("/todos/")
def get_todos():
    return {"message": "Todos list"}
```

Here:

```python
@app.get("/todos/")
```

means:

```text
When user visits GET /todos/, run get_todos()
```

---

# 2. DRF / Django way

In DRF, the view and URL are separate.

## views.py

```python
from rest_framework.views import APIView
from rest_framework.response import Response

class TodoView(APIView):

    def get(self, request):
        return Response({
            "message": "Todos list"
        })
```

## urls.py

```python
from django.urls import path
from .views import TodoView

urlpatterns = [
    path("todos/", TodoView.as_view()),
]
```

Now this endpoint works:

```text
GET /todos/
```

---

# Main difference

FastAPI:

```python
@app.get("/todos/")
def get_todos():
    ...
```

Django/DRF:

```python
# views.py
class TodoView(APIView):
    def get(self, request):
        ...
```

```python
# urls.py
path("todos/", TodoView.as_view())
```

Easy memory:

```text
views.py = what happens

urls.py = where it happens
```

# 3. What is `path()`?

```python
path("todos/", TodoView.as_view())
```

means:

```text
When user visits /todos/,
run TodoView
```

This part:

```python
"todos/"
```

is the URL.

This part:

```python
TodoView.as_view()
```

is the view that should run.

---

# 4. Why `.as_view()`?

You may wonder:

```python
TodoView.as_view()
```

Why not just:

```python
TodoView
```

Because `TodoView` is a **class**.

Django needs to convert that class into a callable view function.

So:

```python
TodoView.as_view()
```

means:

```text
Django, please convert this class-based view into a real view.
```

For now, just remember:

```text
When using APIView, always use .as_view() in urls.py
```

# 5. GET and POST on same URL

In FastAPI:

```python
@app.get("/todos/")
def get_todos():
    pass

@app.post("/todos/")
def create_todo():
    pass
```

In DRF:

```python
class TodoView(APIView):

    def get(self, request):
        return Response({"message": "Get todos"})

    def post(self, request):
        return Response({"message": "Create todo"})
```

Then one URL:

```python
urlpatterns = [
    path("todos/", TodoView.as_view()),
]
```

Now:

```text
GET  /todos/  -> def get()
POST /todos/  -> def post()
```

Same URL, different HTTP method.

# 6. Project `urls.py` vs App `urls.py`

This is very important.

Usually Django has two levels of URL files.

Imagine project:

```text
myproject/
│
├── myproject/
│   └── urls.py        # main project urls.py
│
├── todos/
│   └── urls.py        # app urls.py
```

The project URL file is the main gate.

The app URL file handles one feature/app.

---

# 7. Example with app URL

Suppose we have a `todos` app.

## todos/views.py

```python
from rest_framework.views import APIView
from rest_framework.response import Response

class TodoView(APIView):

    def get(self, request):
        return Response({
            "message": "Todos list"
        })
```

## todos/urls.py

```python
from django.urls import path
from .views import TodoView

urlpatterns = [
    path("", TodoView.as_view()),
]
```

Notice this:

```python
path("", TodoView.as_view())
```

This means:

```text
No extra URL inside this app
```

---

## myproject/urls.py

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("todos/", include("todos.urls")),
]
```

Now the final URL is:

```text
/todos/
```

Why?

Because project URL gives:

```text
todos/
```

and app URL gives:

```text
empty string ""
```

Together:

```text
todos/ + "" = todos/
```

# 9. FastAPI comparison with router

In FastAPI, you might do:

```python
router = APIRouter(prefix="/api")

@router.get("/todos/")
def get_todos():
    pass

app.include_router(router)
```

Django is similar:

```python
# myproject/urls.py
path("api/", include("todos.urls"))
```

```python
# todos/urls.py
path("todos/", TodoView.as_view())
```

So:

```text
FastAPI include_router()
≈ Django include()
```

# 10. Full DRF example

## models.py

```python
from django.db import models

class Todo(models.Model):
    title = models.CharField(max_length=100)
    completed = models.BooleanField(default=False)
```

## serializers.py

```python
from rest_framework import serializers
from .models import Todo

class TodoSerializer(serializers.ModelSerializer):
    class Meta:
        model = Todo
        fields = "__all__"
```

## views.py

```python
from rest_framework.views import APIView
from rest_framework.response import Response
from .models import Todo
from .serializers import TodoSerializer

class TodoView(APIView):

    def get(self, request):
        todos = Todo.objects.all()
        serializer = TodoSerializer(todos, many=True)
        return Response(serializer.data)

    def post(self, request):
        serializer = TodoSerializer(data=request.data)

        if serializer.is_valid():
            serializer.save()
            return Response(serializer.data)

        return Response(serializer.errors)
```

## todos/urls.py

```python
from django.urls import path
from .views import TodoView

urlpatterns = [
    path("todos/", TodoView.as_view()),
]
```

## myproject/urls.py

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("api/", include("todos.urls")),
]
```

Final endpoints:

```text
GET  /api/todos/
POST /api/todos/
```

# Final mental map

| FastAPI                    | Django / DRF                         |
| -------------------------- | ------------------------------------ |
| `@app.get("/todos/")`      | `path("todos/", TodoView.as_view())` |
| endpoint function          | view class                           |
| `APIRouter(prefix="/api")` | `path("api/", include(...))`         |
| URL and logic together     | URL and logic separate               |
| route decorator            | `urls.py`                            |

Main idea:

```text
FastAPI:
URL is attached directly to function.

DRF:
View is written in views.py.
URL is connected in urls.py.
```

Most important line:

```python
path("todos/", TodoView.as_view())
```

means:

```text
When request comes to /todos/,
run TodoView.
```

And if `TodoView` has:

```python
def get()
```

then GET request runs that.

If it has:

```python
def post()
```

then POST request runs that.
